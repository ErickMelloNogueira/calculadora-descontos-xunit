# Calculadora de Descontos

Projeto desenvolvido para a atividade de Garantia da Qualidade de Software.

## Tecnologias
- C#
- .NET 10
- xUnit

## Funcionalidades
- Identificacao da categoria do cliente.
- Calculo de desconto por percentual.
- Verificacao da elegibilidade para cupom.

## Diferenca entre Fact e Theory

O atributo [Fact] e usado para testes individuais sem parametros.

O atributo [Theory] permite executar o mesmo teste com diferentes dados fornecidos por [InlineData].

## Como executar os testes

Na pasta principal do projeto, execute:

    dotnet test
